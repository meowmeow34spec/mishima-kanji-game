# ☕ 살롱 미시마 3D (サロン三島 — Salon Mishima)

**미시마 유키오(三島由紀夫 · Yukio Mishima) 문학 속 필수 한자 80자를 따뜻한 3D 쇼와 문학 찻집에서 서빙하며 저절로 외우는 무료 웹 3D 한자 카페 게임**

[`katakana-cafe`](https://github.com/meowmeow34spec/katakana-cafe)의 손맛과 감각에서 영감을 받아 탄생한 **살롱 미시마 3D (Salon Mishima)**!  
어둡고 딱딱한 한자 암기장 대신, 햇살과 호박빛 조명이 감도는 **3D 쇼와 시대 문학 찻집(純喫茶)** 카운터에 서 보세요.  
『금각사』·『조소』·『가면의 고백』·『우국』 속 등장인물들이 걸어 들어와 주문을 건네면, 카운터 위의 **입체 3D 한자 블록**을 집어 다과와 함께 서빙하다 보면 **억지로 외우지 않아도 80개의 핵심 문학 한자가 머릿속에 생생하게 각인됩니다.**

## ✨ 왜 이렇게 잘 외워질까? (핵심 특징)

1. **한자를 하나도 몰라도 OK! 『☕ 오픈 전 마스터의 1분 한자 과외』**
   - 곧장 서빙에 던져 넣지 않습니다! 스테이지 출근 전 **오늘 손님이 주문할 딱 5글자**를 먼저 눈과 손으로 익힙니다:
     - **1단계 (눈으로 쏙쏙 카드)**: 큼직한 한자(`4rem+`) · 한국어 훈음(`쇠 금`) · **한글 독음 병기(`음독 キン (킨)`)** · 부수 그림 조립 · 1초 연상 스토리 · 원어민 발음 듣기 · 1탭 터치 각인
     - **2단계 (스트레스 제로 손풀기 연습)**: 시간제한·하트 차감 없이 5글자를 가볍게 맞혀 보며, 틀려도 마스터가 다정한 연상 팁으로 다시 알려 줍니다 *(숙련자는 언제든 `예습 건너뛰고 바로 서빙 →` 가능!)*
   - 서빙 중에도 **`📖 배운 5글자 컨닝페이퍼`** 버튼을 누르면 **손님 인내심 타이머가 일시정지**된 채로 방금 배운 5글자를 언제든 다시 확인할 수 있습니다.
2. **실시간 Three.js 3D 카페 & 손맛 나는 서빙 루프**
   - 3D 손님이 문을 열고 종소리와 함께 걸어 들어와 카운터에 앉고, 말풍선으로 주문합니다.
   - 상아빛(`#FFFDF7`) 고해상도 3D 한자 블록을 직접 클릭·터치하거나 단축키(`[1]~[4]`)로 집어 올리면 찻잔·화과자와 함께 포물선을 그리며 서빙됩니다.
   - 정답이면 손님이 기뻐하며 코인(`銭`) 팁이 쏟아지고, **틀리면 손님이 코믹하게 화를 냅니다 ㅋㅋ**
3. **가독성 최우선 (WCAG AAA 급 명도 대비 & 가나 한글 발음 병기)**
   - 한국어 UI(`Pretendard Variable` · `Noto Sans KR`)와 큼직한 한자 명조체(`Noto Serif JP`)로 모바일과 데스크톱 어디서나 눈이 편안합니다.
   - 일본어 히라가나·가타카나가 아직 익숙하지 않은 입문자도 막힘없이 읽을 수 있도록 모든 읽기 보기와 힌트에 **자연스러운 한글 발음(`きんかくじ (킨카쿠지)`)**과 **숙어 칸별 훈음 힌트(`1칸: 쇠 금 · 2칸: 누각 각`)**를 함께 보여 줍니다.
4. **작품에 따라 변하는 4막 3D 창밖 풍경**
   - **제1막 『금각사(金閣寺)』**: 연못 위에 비치는 황금빛 금각사 실루엣과 흩날리는 금박 불티
   - **제2막 『조소(潮騒)』**: 우타지마 섬의 등대, 부서지는 파도와 타오르는 화톳불(`篝火`)
   - **제3막 『가면의 고백 · 녹명관』**: 붉은 벨벳 무대 커튼, 가면과 샹들리에 불빛
   - **제4막 『우국 · 태양과 철』**: 강렬한 진홍빛 태양과 도코노마의 강철 검 장식
5. **코인(`銭`)으로 꾸미는 3D 카페 인테리어 상점 (6종 업그레이드)**
   - 서빙으로 모은 코인으로 카페 소품을 구매하면 **실제 3D 카운터와 벽면에 입체 인테리어가 즉시 추가**되고 강력한 패시브 효과까지 발동합니다!
   - `황금 사이폰 추출기` (+25% 코인 팁) · `벨벳 카운터 좌석` (손님 인내심 +5초) · `금각사 봉황 장식` (스테이지당 1회 실수 방어막) · `쇼와 재즈 축음기` (4콤보 피버 타임 & 코인 2배) · `미시마 초판본 서가` (5초 이내 쾌속 서빙 시 암기 상자 +1 보너스) · `특선 화과자 진열장` (최대 하트 +1)
6. **⚡ 25초 폭풍 주문 러시 & ⚔️ 헷갈리는 한자 3D 보스 결투 (총 8종)**
   - `寺 vs 侍`, `炎 vs 炭`, `憂 vs 優`, `閣 vs 闊`, `刀·刃·切·力`, 그리고 최종 보스 **환영 문호 미시마(`輪·廻·刹·宿·命`)**까지! 회전하는 3D 한자 석판을 깨뜨리는 박진감 넘치는 보스전을 즐겨 보세요.
7. **라이트너(Leitner) 7단계 간격 반복(SRS) & 오답 혼동 행렬**
   - 오늘 배운 한자는 `[0, 1, 2, 4, 7, 14, 30]`일 주기로 **🌅 오늘의 복습**에 다시 등장하며, 자주 헷갈린 한자 쌍은 다음 주문 보기에 우선 배치해 약점을 완벽히 잡아줍니다.

## 📚 미시마 유키오 문학 80한자 커리큘럼 (Yukio Mishima 80-Kanji Curriculum)

총 **80개의 엄선된 문학 한자**가 4개의 막(각 20자, 스테이지 1~4 구성, JLPT `N5`~`N1` 포괄)으로 수록되어 있으며, 모든 한자에 **한국어 훈음 · 부수 분해 · 연상 암기 스토리 · 미시마 원작 명문장 & 한국어 번역 · 대표 숙어 230개**가 완비되어 있습니다.

| 막 (Tier) | 테마 | 수록 대표작 | 수록 한자 (20자) |
| :--- | :--- | :--- | :--- |
| **제1막 (Tier 1)** | **금각의 불꽃과 탐미**<br>*金閣の炎と耽美* | 『금각사 (`金閣寺`)』 | `金 閣 寺 美 鏡 炎 影 僧 幻 滅 焼 灰 鳳 凰 池 光 絶 嫉 妬 生` |
| **제2막 (Tier 2)** | **조소의 바다와 유현**<br>*潮騒の海と幽玄* | 『조소 (`潮騒`)』 · 『풍요의 바다 (`豊饒の海`)』 · 『봄눈 (`春の雪`)』 · 『천인오쇠 (`天人五衰`)』 | `潮 騒 海 豊 饒 波 漁 島 舟 嵐 浜 砂 篝 潜 誓 春 雪 衰 滝 寂` |
| **제3막 (Tier 3)** | **가면의 고백과 애증**<br>*仮面の告白と愛憎* | 『가면의 고백 (`仮面の告白`)』 · 『금색 (`禁色`)』 · 『녹명관 (`鹿鳴館`)』 | `仮 面 告 白 禁 色 罪 偽 恥 劇 演 耽 矢 殉 射 恍 惚 鹿 鳴 館` |

## 🕹️ 플레이 방법 & 조작키 (How to Play)

- **마우스 / 터치**: 3D 카운터 위의 한자 블록을 직접 클릭·탭하거나 하단 선택 버튼 클릭
- **키보드 단축키**:
  - `1` `2` `3` `4`: 1~4번 한자/읽기 블록 즉시 서빙
  - `Enter` / `Space`: 한자 해설 카드(`WordRevealModal`) 확인 후 다음 손님 맞이
  - `Backspace` / `Esc`: 숙어 조립(`build`) 트레이 비우기 또는 모달 닫기
- **3가지 서빙 주문 모드**:
  1. **한자 고르기 (`pick`)**: 손님이 주문한 한국어 뜻·훈음·음독을 보고 알맞은 3D 한자 블록 서빙
  2. **읽기 맞추기 (`recall`)**: 큼직한 한자와 한국어 훈음 힌트를 보고 정확한 일본어 음독/훈독 선택
  3. **숙어 조립하기 (`build`)**: 미시마 문학 숙어(예: `きんかく` · 금각)의 글자 블록을 순서대로 3D 옻칠 쟁반에 조립

## 🛠️ 로컬 실행 및 빌드 (Getting Started)

### 요구 사항 (Prerequisites)
- **Node.js** v18 이상
- **npm** v9 이상

```bash
# 1. 저장소 클론
git clone https://github.com/meowmeow34spec/mishima-kanji-game.git
cd mishima-kanji-game

# 2. 의존성 설치 (React 19 + Three.js + Vite + Vitest)
npm install

# 3. 로컬 개발 서버 실행
npm run dev

# 4. 타입 체크 및 프로덕션 빌드
npm run build

# 5. 전체 단위 + E2E + 3D 통합 테스트 실행 (11개 스위트 · 256개 테스트)
npm test
```
